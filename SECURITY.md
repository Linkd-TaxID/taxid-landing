# Security policy

[Report a vulnerability privately on GitHub](https://github.com/Linkd-TaxID/taxid-landing/security/advisories/new). Use that form for security issues in the TaxID website, its demos, or the Worker source in this repository.

Include the affected page or component, what you observed, its likely impact, and steps to reproduce it safely. Redact credentials, taxpayer identifiers, and personal data. Keep report details out of public issues and pull requests.
